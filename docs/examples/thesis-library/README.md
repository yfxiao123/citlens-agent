# 使用示例：一篇硕士开题的文献基础

这是一次真实的完整用法。目标：为一篇源论文（Bell, Kakhbod, Lettau &
Nazemi 2026, "Glass box machine learning and corporate bond returns",
*JFE*）的复现研究准备开题文献。

## 用户做了什么

把源论文和 9 个检索方向交给 agent（比如"方向1：查新 EBM/玻璃盒 × A股
收益预测""方向4：中国市场制度约束"）。剩下的活是 agent 和 citlens 干的：

1. agent 把每个方向拆成概念块、拟好英文检索词，调 `search`——共跑了
   **11 个子题**；
2. 池子按主题累积在数据目录，跨会话可续用；
3. 逐篇判断相关性后，`fetch` 抓取开放获取全文；
4. 最后按方向汇成文献库、生成引用建议。

## 拿到了什么

```
library/
├── pdf/                 364 篇 PDF 全文
├── text/                362 篇提取正文（可全文检索/精读）
├── by-direction/D1…D9/  9 个方向的阅读清单（每篇带 PDF/仅题录 标记）
├── manifest.jsonl       1072 条总账（含来源与状态）
├── exclusions.jsonl     30 条显式排除（带原因）
└── coverage_audit.json  覆盖审计：1096 条的池对 131 个锚点文献的覆盖率
```

主交付物是《文献分类与引用建议》：源论文自引的 91 条参考文献逐条经
Crossref/OpenAlex 核验、分成 8 个主题组并给出每组引用理由；再按 9 个
方向给出补充引用建议。没拿到全文的 736 条也不含糊，单独列出每条的
可尝试获取渠道。

本目录的两个样例：

| 文件 | 是什么 |
|---|---|
| [sample-search-report.md](sample-search-report.md) | `search` 一次检索的报告（现行版输出格式） |
| [sample-reading-list.md](sample-reading-list.md) | 一个方向的阅读清单（毕设真实产物，节选） |

## 两句实话

- 清单里能看到个别字面撞词的条目（比如讲"可解释机器学习"撞进来一篇
  fitbit 数据论文）——多路召回保证广度，逐篇终审是 agent 和你的活，
  工具不替你判断。
- 毕设检索跑于 2026-10 中旬的早期版本（报告里的家族名称与现行版不同）；
  检索报告样例取自现行版的一次真实运行，仅示格式。
